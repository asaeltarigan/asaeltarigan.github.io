A browser-only converter: paste rich text from Word, Google Docs, a web page or an email and get clean Markdown back.

- Clipboard HTML is converted directly, so bold, italics, headings, links, images, nested lists, blockquotes and tables survive the trip
- A second tab takes raw HTML when you have markup rather than a rendered page
- Live conversion as you paste, with toggles to drop links, drop images or turn off GFM tables
- Copy to clipboard or download a `.md` file

No upload, no server, no tracking and no build step. The converter libraries are vendored rather than loaded from a CDN, so the page works offline and does not fail when someone else's server does.
