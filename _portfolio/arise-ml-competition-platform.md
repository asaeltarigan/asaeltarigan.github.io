A Kaggle-style ML competition platform that makes machine learning hands-on and competitive for BINUS students. Built, deployed, and operated by me: I teach it, I build it, I run it.

- FastAPI backend, self-hosted on a single $5 VPS with a cloudflared tunnel
- Daily submission caps (30/day) with NIM-gated access
- Admin analytics: submission logs, leaderboards, open/close flags
- iOS, Android, and web clients all hit the same API
- Auto-graded leaderboards turn coursework into a real competition
