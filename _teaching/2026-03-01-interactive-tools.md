I build visual, interactive tools for teaching abstract machine learning concepts. The flagship is a browser-based backpropagation teaching tool built on a 4-beat story: *guess, measure, blame, nudge*. An XOR demo serves as the hero example. Visual and interactive beats abstract wherever possible.
