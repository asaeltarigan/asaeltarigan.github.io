Applied Computer Vision for the Artificial Intelligence program, built around PyTorch: from neural network fundamentals through image classification, object detection, and segmentation, to generative vision with autoencoders and GANs.

## Sessions

- **Sessions 1-3: Neural Network Foundations** — artificial neural network fundamentals, PyTorch fundamentals, building a deep neural network with PyTorch
- **Sessions 4-6: Image Classification** — introducing convolutional neural networks, transfer learning for image classification, practical aspects of image classification
- **Sessions 7-8: Object Detection** — basics of object detection, advanced object detection
- **Sessions 9-10: Segmentation and Applications** — image segmentation, applications of object detection and segmentation
- **Sessions 11-13: Generative Vision** — autoencoders and image manipulation, image generation using GANs, review and presentation

## Resources

- **Supplementary:** Ayyadevara and Reddy. *Modern Computer Vision with PyTorch* (O'Reilly)
- **Tools:** PyTorch, torchvision, Google Colab

Full session materials and lab guides are shared with enrolled students only.
