Graduate course at BINUS University on the lifecycle of production ML systems. Covers experimentation, model serving, monitoring, and the engineering discipline behind deployed machine learning.

## Weekly Sessions (13 weeks)

| Week | Topic | Focus |
|------|-------|-------|
| 1 | Introduction to MLOps and the ML Lifecycle | Scope of MLOps, from data to production |
| 2 | Data Management for MLOps | Data versioning, feature stores, validation and quality checks |
| 3 | Model Development and Experiment Tracking | Logging metrics and parameters, model registry, reproducibility |
| 4 | CI/CD for Machine Learning | Principles, automated testing for ML, GitHub Actions, GitLab CI/CD |
| 5 | Production-Ready ML Pipelines | Orchestration, pipeline as code, Kubeflow, Airflow |
| 6 | Model Deployment Strategies | Batch vs real-time inference, FastAPI serving, REST and gRPC |
| 7 | Containerization and Orchestration | Docker for ML models, Kubernetes for scalable serving |
| 8 | Model Monitoring: Performance and Data Drift | Monitoring metrics, detecting data and model drift |
| 9 | Advanced Monitoring and Alerting | Dashboards, alerting strategies, Prometheus, Grafana |
| 10 | Retraining and Model Updates | Scheduled and drift-triggered retraining, A/B testing, rollback |
| 11 | MLOps Security and Governance | Pipeline security, access control, XAI and responsible AI |
| 12 | Scaling MLOps and Cloud Platforms | AWS SageMaker, Azure ML, GCP Vertex AI, cost optimization |
| 13 | Project Presentations and Future of MLOps | Student projects, emerging trends, Generative AI MLOps |

## Assessment

Applied project building and operating a production ML service, plus written components.

## Resources

- **Textbook:** Gift, Deza, and others. *Practical MLOps: Operationalizing Machine Learning Models* (O'Reilly)
- **Tools:** MLflow, Docker, Kubernetes, FastAPI, Prometheus, Grafana
