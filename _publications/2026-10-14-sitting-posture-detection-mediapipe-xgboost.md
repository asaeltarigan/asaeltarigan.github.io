Final-year BINUS student capstone, supervised by Gabriel Asael Tarigan. A robust sitting posture detection interface using MediaPipe and an optimized XGBoost classifier, introducing scale-invariant geometric features (including normalized nose-to-shoulder depth) with a temporal smoothing window, deployed as a live feedback system.
