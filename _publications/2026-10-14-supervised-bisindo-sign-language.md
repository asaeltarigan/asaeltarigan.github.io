Final-year BINUS student capstone, supervised by Gabriel Asael Tarigan. BISINDO Bridge is an end-to-end dual-hand Indonesian sign-language gesture recognizer integrated into a small-room video-meeting testbed, with an 84-dimensional landmark vector classified by a compact 1-D CNN and deployed fully in-browser via ONNX Runtime Web so recognition never leaves the client.
